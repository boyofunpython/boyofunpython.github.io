# 整體檢查：2026-10-27

## 已修正並驗證

- 教室原本固定連到 `boyofunpython.ddns.net:9000`，已改為公共 PeerServer Cloud，使用 TLS 443 與 PeerJS 套件預設 ICE 設定。本次環境檢測舊 DDNS 無法解析。
- 教師切換到編輯器會銷毀教室，造成剛分享的連結失效；現已讓教室保持掛載，直到明確結束連線或關閉／重整分頁。學生接收程式另存、編輯後回到教室，仍可回傳給同一教師。
- 分享 URL 保留部署路徑，只分享目前 peer ID；不夾帶其他 query。學生開啟連結後 ID 自動帶入，再自行輸入暱稱加入。剪貼簿拒絕時保留可手動複製的完整 URL。
- 單一學生資料通道失敗不會關閉整間教室；廣播遇到一個失效通道時會繼續送給其他人。訊號重連保留 ID，避免重複學生通道；晚到的資料連線不會取消訊號重連的逾時計時。
- 收件匣保留接收時的來源與檔名，斷線後仍可另存；限制每份程式及收件匣數量，遠端 metadata 僅作為有長度限制的文字顯示。

## 跨頁面通訊補強

- 「教室通訊」在編輯器、範例、AI 與 Console 持續運作；通知保留編輯焦點，開啟通訊仍可編輯程式。
- 學生送交固定版本與問題，接收端確認收件；老師全文預覽、只解析語法、不執行學生程式，並只回覆原送交連線。其他同學相同的封包 ID 不會改變回覆對象。
- 送交／接收不改寫原檔；正檢查的程式在收件匣滿時仍保留，離線回覆失敗保留草稿。訊息與程式筆數、文字長度有上限，重整清除本分頁通訊紀錄。
- 新增 6 項協定與介面測試，涵蓋錯誤封包、去重、回覆隔離、快照、快捷鍵不誤執行、焦點、手機與無障礙掃描。

## 即時語音補強

- 老師可對所有已連線學生開麥廣播，學生可只對老師發話；雙向同時發話使用獨立單向音訊連線，接聽不會擅自取得接收端麥克風。
- 跨頁面與收合後保持語音並顯示關閉按鈕；支援靜音、音量、手動啟用收聽與自動播放阻擋提示。離開教室與取消晚到的麥克風授權皆釋放音軌。
- 新增 7 項語音測試，檢查權限／裝置錯誤、單一語音失敗保留資料連線、來電來源及停止 ID、取消授權、晚加入、手機與無障礙。
- 公共服務語音驗收使用合成音源與三個隔離 Chromium 環境，驗證真實雙向 RTP、接收端非零音訊能量及播放進度；不使用真實麥克風，不宣稱跨校網路或人耳音質測試。

## 外部依賴與未涵蓋範圍

- **舊 CSV 相對路徑來源仍失效**：`python/studio_runtime.py` 的 `loadCSV()`／`aloadCSV()` 會將相對路徑接到 `https://boyofunpython.ddns.net:8787/`。本次 HEAD 檢測回報 DNS 無法解析，舊資料來源尚未搬遷。需要新的資料來源才能恢復既有相對檔名；可改用可存取且允許 CORS 的完整 CSV URL，或先用內嵌 CSV。此次沒有未知的原始資料可搬遷，因此不猜測替代網址。
- 公共 PeerJS、STUN/TURN 與校園網路的可用性會變動。三瀏覽器測試證明當下服務與流程運作，沒有涵蓋所有跨校／對稱 NAT／受限防火牆環境。[PeerJS FAQ](https://peerjs.com/client/faq)。
- AI API 的自動測試使用合成金鑰及回覆；沒有呼叫付費模型或驗證個別老師帳號的權限。所有 BYOK 設定仍需使用者自己的服務帳號與網路允許。
