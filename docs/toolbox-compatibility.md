# 舊版工具箱對照與維護

參考版本為 `legacy` 分支的 `66ac086`，來源 `blockmirror/block_mirror.js`。原始分類、範例與順序快照保存在 `tests/fixtures/legacy-toolboxes.json`，檢查不依賴已移除的 BlockMirror 程式。

| 模式   | 舊版              | 新版                          |
| ------ | ----------------- | ----------------------------- |
| 基礎   | 11 分類、65 範例  | 11 分類、83 選項              |
| 完整   | 18 分類、118 範例 | 20 分類、174 選項             |
| turtle | 24 範例           | 35 操作與範例，兩種模式都提供 |

選項數包含不同預設值或形狀的同類方塊；不同模式會重複提供共同工具。新版完整版額外保留 turtle 與獨立字典分類。

基礎分類為變數、資料數值、工具、數學運算、邏輯判斷、迴圈、畫圖🐢、函式、資料轉換、資料串(List) 與字典資料。完整版另有物件、輸入函式庫、流程控制、圖表、檔案、內建函式、資料串／字串操作、切片、資料產生器與註解等分類。

## 操作相容性

- turtle 恢復前進／後退、左右轉、座標與方向、提筆／落筆、筆寬／筆色、填色、背景、圓形、印章、一般／指定字型寫字及位置查詢，另提供原點、點、顯示／隱藏、形狀與動畫控制。預設值能直接編輯，使用繪圖方塊會自動產生 `import turtle`。
- 函式、類別、匯入、例外處理、檔案資源、元組、集合、字典、切片與產生式都使用具欄位／連接點的方塊；進階或未支援的組合仍保留完整 Python 文字，不刪除程式。
- 隨機工具自動匯入 `random`，圖表工具自動匯入 `matplotlib.pyplot`。`plt.show()` 使用 Worker 可執行的 Agg 後端產生圖片；舊 `format_mime(plt)` 也能顯示圖形。第一次使用科學套件仍需網路，套件準備上限 90 秒，實際執行上限 30 秒。
- 保留舊版功能，修正舊範例中 `lower('')`／`upper('')`／`title('')` 的多餘參數，以及 `isinstance` 缺少型態參數的預設值。重複的 `strip` 與字典產生式不再以完全相同內容重複列出。
- 指定字型的 turtle 文字正確套用像素大小與粗體／斜體；一般字串中的換行字元不會因區塊縮排而改變。

## 防止工具遺漏的檢查

```sh
npm run test:toolbox
npm run build
npm test
```

工具箱檢查會以舊版清單比對分類、各分類選項數與實際呼叫操作；建立全部 257 個預設方塊，驗證產生的 Python 語法及 AST 往返，再執行 14 組程式比對結果。Playwright 另驗證所有分類選單、實際拖曳、參數修改、字型繪圖、完整版類別／檔案／字串與前後端整合。報告在 `artifacts/toolbox-coverage.json`，截圖在 `artifacts/toolbox-*.png`。
